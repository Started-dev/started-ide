# started-ide — archived prototype

This repository was the **cloud inference IDE**. That product is retired.

Started is now a **local-first runtime for verified agent kits**.

| Go here | For |
| --- | --- |
| [`Started-dev/started`](https://github.com/Started-dev/started) | Spec, engine, CLI, official kits |
| [`Started-dev/runner`](https://github.com/Started-dev/runner) | Isolated execution |
| [`Started-dev/started-ai`](https://github.com/Started-dev/started-ai) | Optional BYO model adapter |
| [started.dev](https://started.dev) | Studio (viewer) |

The tree under `src/` and `api/` is frozen prototype code (Privy, MCP, hosted agents). Do not extend it. New work lands in `started`.

A committed `.env` was removed from `main`. Rotate any keys that ever lived in this repo.
